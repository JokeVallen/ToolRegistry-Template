Registry 工作台

选一个注册库文件夹，在这里校验清单、核对制品摘要、重写 index.yaml。 整页离线运行，文件不离开这台机器。
Pick a registry folder to validate its manifests, check artifact digests and rewrite index.yaml. Fully offline; nothing is uploaded.

1. 选文件夹 / Pick the folder

选择包含 payloads/ 的那个目录

浏览器的文件夹选择器只在这一个动作里给你读取权限；页面不保存也不上传任何文件。

2. 清单 / Manifests

还没选文件夹。

3. 制品 / Artifacts

清单读完之后逐个体检：存在、大小、sha256。

压缩包内部（contentRoot、files）需要解压才能核对， 这一步留给 node tools/registry.mjs validate。

4. 目录 / index.yaml

选文件夹后，这里会对比现有的 index.yaml 与重新生成的目录。

这个页面和 utool 用同一套规则：schema、清单类、目录生成函数都是从 导入工具的源码里内联进来的，不是另写一份。
