Registry 起步包 / Registry starter

这是 ToolRegistry 数据格式的模板仓库：一份可以直接用、也可以直接改成你自己 Registry 的最小集合。先双击 index.html：它是唯一入口，按"你来做哪件事"分四扇门—— 第一次跟走、校验整库、写新清单、只验一份清单。

A starter registry for the ToolRegistry format. Open index.html first: one entry point with four doors - start from zero, validate the registry, write a manifest, or check a single one.

开始用 / Start from this template

  • 在线看：https://jokevallen.github.io/ToolRegistry-Template/（不用下载）
  • 用模板建自己的仓库：仓库页右上角 Use this template → Create a new repository
  • 只想本地跑一遍：git clone https://github.com/JokeVallen/ToolRegistry-Template.git my-registry

这里有什么 / What is here

index.yaml              目录（自动生成，不手改）
payloads/example-hello/ 一个可校验、可规划、可安装的示例工具
schema/                 校验依据
tools/                  registry.mjs 与四个离线页面（validate / editor / guide / workbench）
template/               骨架 yaml
docs/                   格式规范等文档
index.html              唯一入口：四扇门（引导 / 整库校验 / 写清单 / 单份校验）
START-HERE.html         七步引导（从入口页进入，或直接打开）

三条命令 / Three commands

node tools/registry.mjs validate        # 校验整份注册库
node tools/registry.mjs write-index     # 改过 payload 之后重新生成 index.yaml
node tools/registry.mjs check-index     # CI：只检查目录是否过期

需要 Node.js 22.15 以上（导入工具用了 22.15 才有的 zstd 解压）与 git。校验器在导入工具里。 两个仓库放成同级目录即可自动发现；否则设 UTOOL_CORE。

Requires Node.js 22.15 or newer (the import tool uses the zstd support added in 22.15) and git. The validator lives in the import tool: keep the two repositories side by side, or set UTOOL_CORE.

配对的导入工具 / Matching import tool

本模板对应 ToolImport 1.2.2：https://github.com/JokeVallen/ToolImport/releases/tag/v1.2.2

This template is written for ToolImport 1.2.2.

示例工具 / The example tool

payloads/example-hello 是一个真的能装进 Godot 工程的单文件工具。第一次跑通之后，复制它、改掉 id 与内容，就是你的第一个工具。

payloads/example-hello is a real one-file Godot tool. Copy it, rename it, replace the contents.
