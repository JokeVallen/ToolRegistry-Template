Registry 起步包

一份能直接用的注册库。以下页面全部离线运行，不需要 Node，也不联网。

对应 ToolImport 1.2.2 · 示例工具 example-hello

①

我是第一次来，跟着走

七步：确认环境 → 装配套的导入工具 → 拿到注册库 → 校验 → 装第一个工具 → 在编辑器里看到它。每步都有命令、复制按钮，以及"怎么算成功"的自检。New here: follow the seven steps from an empty machine to a working install.

→
②

校验这份注册库 / 重写目录

选一次文件夹，逐条列出清单问题、制品摘要不符之处，并告诉你 index.yaml 是否过期——过期就直接下载新的。Validate the registry: manifests, artifact digests, and whether index.yaml is current.

→
③

写一份新的 tool.yaml

表单式录入，选引擎、填版本、把制品拖进去，摘要与空格由页面算，不用碰 YAML 缩进。Write a manifest: fill a form, drop the artifact in, get size and sha256 computed for you.

→
④

只校验一份清单

把 tool.yaml 拖进去，逐条告诉你哪里不合规、为什么。不读制品，不碰目录。Check one manifest: is it shaped the way the format requires?

→

格式规范

规范、字段速查（由 schema 生成）、术语表、错误码。中英各一份。The specification, the field reference, the glossary and the error codes.

→

这些页面用的是同一套规则：schema、清单类、目录生成函数都是从导入工具的源码里 内联进来的，所以页面上"通过"的东西，命令行也认。

命令行（给流水线）

$ node tools/registry.mjs validate # 全量校验，CI 的入口
$ node tools/registry.mjs write-index # 改过 payload 之后重建目录
$ node tools/registry.mjs check-index # 只检查目录是否最新

日常维护用上面的页面就够了；命令行需要 Node 22.15 以上，是给自动化用的同一批检查。
