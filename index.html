⌘

扩展：新引擎 / 新容器格式 / 新前端Extend: an engine, a container format, a front end

三个扩展点：providers/engine-*（引擎知识）、容器 handler（解压与文件清单）、前端（读清单、调 CLI）。核心不需要改。非游戏工程走的就是第一条：加一个通用适配器。Three seams, none of them inside the core. A non-game project starts with the first one.
